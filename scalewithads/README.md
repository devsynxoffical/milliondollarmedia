# Scale with Ads

Next.js funnel site for [scalewithads.us](https://scalewithads.us).

## Routes

- `/` — main hub
- `/leadpilot` — Lead Pilot (personal ads management)
- `/metads` — LTO Meta Ads VSL
- `/privatemastermind` — Hidden Facebook Interest mastermind
- `/book` — application form

## Develop

```bash
npm install
npm run dev
```

Videos stream from the original CDN. Large local `.mp4` files are gitignored.
